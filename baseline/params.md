---

## 2. 逐项选择理由

### 2.1 时间切片：2015–2025 (Slice = 1)

- **为什么是 2015–2025**：Transformer 架构 2017 年才提出，此前无相关研究；检索截止 2026-04-14，2026 年数据不完整，故上限取 2025
- **为什么 Slice = 1**：该领域处于高速扩张期，年度变化显著。1 年切片可精确追踪 ViT (2021)、Swin (2021) 发表后的年度响应，若用 2–3 年切片会抹平 2024 年的爆发信号

### 2.2 节点选择：g-index (k=25)

- **为什么用 g-index 而非 Top N**：147 篇 DL 纯净集中，不同时间切片文献量差异极大（2017–2021 年共仅 12 篇，2024–2025 年共 115 篇）。Top N 固定阈值在早期切片会引入低相关节点，在后期切片会遗漏重要节点。g-index 按各切片内部被引分布自适应调节，在文献量悬殊的场景下比 Top N 更稳健
- **为什么 k=25**：k 值决定每个切片纳入的最大节点数上限。147 篇文献量偏小，k 过大会引入噪声（低被引文献成为节点），k 过小（如 5–10）会丢失重要的方法论文献。k=25 在覆盖度与信噪比之间取得平衡，也是 CiteSpace 官方推荐的中小数据集起步值

### 2.3 网络裁剪：Pathfinder + Pruning sliced networks

- **为什么用 Pathfinder**：Pathfinder 算法保留网络中"最短路径"上的关键边，剔除冗余连接。共被引网络本身是全连接或近全连接的，不经裁剪无法识别骨架结构。Pathfinder 不依赖主观阈值，由网络拓扑本身决定保留哪些边，比 Minimum Spanning Tree 保留更多结构信息
- **为什么 Pruning sliced networks**：对每个时间切片独立执行裁剪，避免早期切片的结构信息被后期切片的大量新节点淹没。不做此裁剪会导致时间线视图过于杂乱，关键路径不可辨识

### 2.4 聚类标签：LLR (Log-Likelihood Ratio)

- **为什么用 LLR 而非 LSI 或 MI**：LLR 从施引文献的标题/摘要中提取聚类标签，标签语义更贴近文献实际内容。相比 LSI（潜在语义索引）偏向高频通用词、MI（互信息）对低频词敏感，LLR 在术语代表性与统计稳健性之间平衡最好，是文献计量学中最常用的聚类标签算法

## 3. Kleinberg 突现检测参数

| 参数 | 设定值 | 理由 |
|---|---|---|
| 算法 | Kleinberg (2003) | 基于隐状态概率模型识别词频的"突然变化"，而非绝对值升降。适合该领域文献量基数快速变化的特点 |
| α (s) | 2 | 控制突现检测的灵敏度。α=2 平衡了假阳性与漏检，α 越小越敏感但假阳性越高 |
| γ | 1 | 控制状态转移惩罚。γ=1 为默认值，避免过度惩罚短期波动 |
| 最小持续 | 2 年 | 剔除仅维持 1 年的瞬态噪声，确保保留的突现词具有可解释的结构性意义 |
| Top 展示 | 25 | CiteSpace 自动检出后，按突现强度与主题代表性筛选 Top 25 展示于正文，完整列表见 `outputs/keyword_bursts.csv` |

## 4. 未使用参数的说明

| 未使用 | 原因 |
|---|---|
| Top N% | 不适合该数据集跨切片文献量差异极大的特征，固定百分比在早期切片（文献极少）会放大噪声 |
| Cosine 相似度 | 关键词共现网络默认使用 Cosine，本项目保留默认值，但不作为主要调参对象 |
| MST 裁剪 | 过于激进，会丢失 Pathfinder 保留的冗余关键路径，不适合本研究的探索性分析目标 |

## 5. 复现核查清单

任何人在 CiteSpace 中复现本项目图谱时，依次设置以下参数即可得到相同结果：

1. 新建项目 → Data Directory 指向 `Data/`（含 DL 纯净集 147 篇）
2. Time Slicing: From 2015 To 2025, Years Per Slice = 1
3. Node Types: 按分析目的选择 Keyword / Reference / Cited Reference
4. Selection Criteria: g-index, k = 25
5. Pruning: 勾选 Pathfinder 与 Pruning sliced networks
6. 运行后 → Clustering → LLR → 导出可视化
