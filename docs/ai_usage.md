## 2. AI 使用边界（本项目的红线）

### AI 承担的工作
- 文献检索式迭代建议（人工审核后执行）
- 数据清洗脚本编写（人工检查输出结果）
- 图表参数调整与排版优化
- 文档结构与措辞润色
- Git 版本管理与提交信息整理
- HTML 展示页前端代码编写
- 课程补件模板生成

### 人工必须承担的工作
- 研究选题判断与研究问题设计
- CiteSpace 图谱的参数选择与结果解读
- DL 语义筛选的关键词规则制定与边缘文献判定
- 所有数值结论的核对与确认（N/E/Q/S 等指标）
- Claim-Evidence 表的论证逻辑审核
- 最终定稿的全文通读与签字确认

### AI 不可做的事
- 代替作者提出核心学术论点
- 编造引用或数据
- 全文代写（本项目所有章节均由人工逐段审核）
- 虚假引用（所有引文均来自 WoS 原始导出记录）
- 作为作者署名

## 5. 版本与可复现性

- 所有分析脚本落盘到 `src/`，依赖声明在 `requirements.txt`
- CiteSpace 参数固化在 `baseline/params.md`
- 检索式版本管理在 `config/query.yaml`（v0/v1/v2-final）
- 数据版本以 WoS 导出时间戳（2026-04-14）锁定

任何人均可通过：
```bash
pip install -r requirements.txt
python run_pipeline.py
```
复现核心分析管道。
