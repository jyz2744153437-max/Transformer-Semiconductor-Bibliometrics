# 分析口径对照表

> 用途：统一说明本项目中 `643` 全量集、`147` DL 纯净集，以及 CiteSpace 正式图谱与 Python 辅助子图之间的关系。  
> 生效日期：2026-06-03  
> 适用范围：README、`paper/manuscript_v1.md`、`项目展示.html`、`reports/*`、`outputs/*`

---

## 1. 统一原则

本项目自本版起采用以下唯一口径：

1. **正式答辩口径以 `147` 篇 DL 纯净集为根本。**
2. **凡属于 CiteSpace 核心图谱的结果，均以 `147` 篇为正式输入。**
3. **`643` 篇全量集仅用于宏观统计、检索边界说明与噪声对照。**
4. **Python 交互网络或复核脚本如果给出更小的节点数/突现词数，属于同一 `147` 数据集的辅助子图或算法复核结果，不替代 CiteSpace 正式口径。**

## 4. 为什么会出现 `383 vs 89`

这两个数字不是两套不同数据集，而是**同一 `147` 篇 DL 纯净集在两种输出层级下的结果**：

- `383 / 1262`：CiteSpace 正式共被引网络的原始图谱规模，用于论文、README、HTML 的正式知识基础分析。
- `89 / 200`：为了交互浏览、里程碑排序和 Python 指标计算，从同一批 `147` 篇文献派生出的**压缩子图**。

因此，正式答辩时应承认：

> **共被引网络的正式结果是 CiteSpace 图谱 `N=383, E=1262`；`89/200` 只是同源辅助子图。**

---

## 5. 为什么会出现 `25 vs 17`

这两个数字同样不是两套不同数据集，而是**同一 `147` 篇 DL 纯净集在两种工具下的输出差异**：

- `25`：CiteSpace 正式突现检测结果，用于主稿、README、HTML 的正式三阶段叙事。
- `17`：本地 Python 对 Kleinberg 算法的复核结果。由于关键词预处理、分词合并和实现细节不同，原始条目数较少。

因此，正式答辩时应承认：

> **突现检测的正式结果以 CiteSpace 导出为准；Python 脚本结果仅用于辅助核对趋势方向。**

## 6. 2025 / 2026 年边界说明

为避免时间边界被追问，统一采用以下说法：

- 项目正式时间范围写作 `2015-2025`
- 检索冻结时间为 `2026-04-14`
- `2026` 年 Early Access 记录不进入主图展示
- 凡涉及 `2025` 年增长或最新前沿时，一律表述为：
  - “截至本次检索窗口”
  - “在当前样本内”
  - “显示出继续上升/收敛的趋势”

避免直接写成“已经完全确认的全年结论”。
