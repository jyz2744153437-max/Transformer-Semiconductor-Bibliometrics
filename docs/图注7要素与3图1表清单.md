## 3. 核心图表图注对照

### Fig.1 年发文趋势

| 要素 | 本项目取值 |
|---|---|
| 研究对象 | Transformer 在半导体制造领域的年度发文变化 |
| 数据来源 | Web of Science Core Collection |
| 时间范围 | 2015-2025；主趋势解释排除 2026 Early Access |
| 分析单位 | 年度文献篇数、增长率、阶段划分 |
| 工具版本 | Python/pandas；HTML 展示页辅助可视化 |
| 阈值参数 | 全量集 643 + DL 纯净集 147 双口径；趋势解释以 DL 纯净集为主 |
| 视觉元素含义 | 柱/线表示年度发文与增长率，阶段标记表示萌芽期、加速期、爆发期 |

### Fig.2 合作网络

| 要素 | 本项目取值 |
|---|---|
| 研究对象 | DL 纯净集中作者合作关系 |
| 数据来源 | Web of Science Core Collection DL 纯净集 |
| 时间范围 | 2015-2025 |
| 分析单位 | 作者节点与合著边 |
| 工具版本 | Python/networkx + Plotly/Pyvis |
| 阈值参数 | 发文量不低于 2 的作者进入可视化网络；贪婪模块度社团检测 |
| 视觉元素含义 | 节点表示作者，连线表示合著关系，节点大小表示连接度，颜色表示社团 |

### Fig.3 关键词/共被引/主题演化图

| 要素 | 本项目取值 |
|---|---|
| 研究对象 | 关键词热点、共被引知识基础与主题演化 |
| 数据来源 | Web of Science Core Collection DL 纯净集 147 篇 |
| 时间范围 | 2015-2025 |
| 分析单位 | 关键词、被引文献、聚类标签 |
| 工具版本 | CiteSpace 6.4.1 |
| 阈值参数 | Time Slicing=2015-2025, 1 year/slice；g-index k=25；Pathfinder + Pruning sliced networks；LLR 标签 |
| 视觉元素含义 | 节点大小表示频次/被引强度，颜色表示时间或聚类，连线表示共现/共被引关系，紫色外环表示高中介中心性 |

## 4. 正文与展示使用原则

- 正文只保留最服务主线的 3图1表，其他高质量图谱放 README、HTML 或附录。
- 每张图表必须能回答至少一个 RQ。
- 每条核心 Claim 必须能回到图表、指标、Top 列表、代表文献或检索记录。
- 不用低质量截图；若用 CiteSpace 原图，必须同时说明参数和视觉元素含义。
