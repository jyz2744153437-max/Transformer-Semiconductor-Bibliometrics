# 引用库与 AI 使用伦理说明

> 更新日期：2026-06-03
> 目的：说明本项目的参考文献来源、引用管理方式，以及大语言模型在课程项目中的使用边界与人工复核责任。

---

## 1. 参考文献与引用库来源

### 1.1 主数据来源

- **Web of Science Core Collection**
- 检索范围：`2015-01-01` 至 `2025-12-31`
- 最终主数据集：`643` 篇
- DL 纯净子集：`147` 篇

### 1.2 参考文献层级

本项目引用和讨论的文献主要来自三层：

| 层级 | 作用 | 代表文件 |
|---|---|---|
| 数据层 | 构成文献计量样本的 WoS 原始记录 | `Data/download_1-500.txt`、`Data/download_501-643.txt`、`Data/download_1-147.txt` |
| 方法层 | CiteSpace、Kleinberg、PRISMA 等方法依据 | `reports/methodology.md`、`reports/prisma_flowchart.md` |
| 论证层 | 支撑结论的 milestone 文献与代表研究 | `reports/milestone_selection.md`、`reports/claim_evidence_table.csv`、`项目展示.html` |

### 1.3 引用管理方式

- 文献计量样本的原始元数据保留在 WoS 导出文本与筛选结果 CSV 中。
- 关键代表文献通过共被引网络、里程碑筛选表与结果段落进行二次整理。
- 当前仓库未单独维护 Zotero/EndNote 数据库文件；课程项目阶段以 WoS 原始导出 + Markdown 结构化记录为主。
- 代表性文献优先在以下文件中统一调用：
  - `reports/milestone_selection.md`
  - `reports/structural_variation.md`
  - `reports/results_paragraph_v1.md`
  - `paper/manuscript_v1.md`

## 2. AI / LLM 使用边界

### 2.1 AI 参与的工作类型

本项目中，大语言模型主要参与以下任务：

- Markdown 文档重组与格式化
- HTML 展示页结构与文案润色
- Python / JavaScript 辅助脚本编写与调试
- 图谱内容的辅助解读与表达候选生成
- 版本整理、Release 文案草拟、课程补件归档

### 2.2 明确不交给 AI 决定的事项

以下内容必须由人工主导、人工确认，不以 AI 输出直接替代：

- 选题方向与研究问题
- WoS 检索式的最终版本
- 文献是否纳入的筛选判断
- 计量结果是否成立的实质判断
- 时间范围、文献数量、核心指标等事实口径
- 最终结论是否与图谱和代表文献一致

### 2.3 人工复核原则

- **事实可追溯**：涉及数字、时间范围、文献量、聚类指标时，必须回到原始输出或对应脚本验证。
- **结论可回链**：任何公开表达的主判断，都应能在 `claim_evidence_table.csv`、图谱或代表文献中找到依据。
- **不伪造来源**：AI 不得凭空生成未检索到的参考文献、被引次数或图谱指标。
- **不伪造事件**：未发生的课堂反馈、预答辩意见与现场问答一律不写成既成事实。

## 3. 本项目中的 AI 透明声明

### 3.1 使用原则

- AI 是**辅助组织与表达工具**，不是研究责任的转移对象。
- 项目中的数据源、分析结论与最终对外表述均由人工复核后保留。
- AI 帮助提升了整理速度、代码实现效率与展示质量，但不替代课程作业应有的判断与负责。

### 3.2 风险控制

针对大模型常见风险，本项目采取以下控制方式：

| 风险 | 控制方式 |
|---|---|
| 幻觉引用 | 所有代表文献均回查到 `reports/`、论文主稿或 WoS 导出来源 |
| 数字漂移 | 统一以 `643 / 147 / 2015-2025` 为唯一口径，并在 README、HTML、Release 草案同步 |
| 过度修辞 | 学术页面坚持“结论句 + 证据句”结构，不以空泛赞美替代分析 |
| 过程不透明 | 单独保留课程补件文档，说明 AI 参与边界与人工复核流程 |

## 4. 对课程答辩的意义

- 这份说明的重点不是“证明用了很多 AI”，而是说明**用了哪些、没让它决定哪些、最终如何保证学术可信度**。
- 对老师而言，最重要的信息是：本项目并未把 AI 当作黑箱代写工具，而是将其纳入可解释、可复核的人机协作流程。
