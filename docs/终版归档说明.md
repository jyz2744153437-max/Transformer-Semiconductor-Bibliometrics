# 终版归档说明

> 更新日期：2026-06-03
> 目的：为课程收尾阶段提供一个统一入口，说明最终应提交、展示和备查的材料分别在哪里。

---

## 1. 最重要的四个入口

| 类型 | 文件 | 作用 |
|---|---|---|
| 项目总入口 | `README.md` | 概览项目内容、方法、结构与公开链接 |
| 答辩主舞台 | `项目展示.html` | 现场主讲材料，也是 GitHub Pages 对外展示核心 |
| 论文主稿 | `paper/manuscript_v1.md` | 学术写作主文本 |
| 课程补件中枢 | `docs/课堂进度对照矩阵.md` | 将课堂要求与仓库成果逐项映射 |

---

## 2. 分类归档

### A. 核心展示层

- `项目展示.html`
- `Visual output/`
- `outputs/*_network.html`

适合老师、同学、课程评审直接查看。

### B. 学术写作层

- `paper/manuscript_v1.md`
- `reports/results_paragraph_v1.md`
- `reports/methods_draft.md`
- `reports/research_questions.md`
- `reports/review_type_statement.md`

适合查看“怎么把图谱变成论文论证”。

### C. 方法与证据层

- `reports/claim_evidence_table.csv`
- `reports/method_result_map.csv`
- `reports/milestone_selection.md`
- `reports/technology_roadmap.md`
- `reports/structural_variation.md`
- `reports/methodology.md`

适合查看“结论是如何被证据支撑的”。

### D. 数据与复现层

- `Data/`
- `src/`
- `run_pipeline.py`
- `run_pipeline.js`
- `requirements.txt`
- `config/query.yaml`

适合查看“是否可追溯、可复核、可重跑”。

### E. 课程过程补件层

- `docs/课堂进度对照矩阵.md`
- `docs/引用库与AI伦理说明.md`
- `docs/智能体工作流总览.md`
- `docs/写作修订日志.md`
- `docs/预答辩与PR-Review准备包.md`

适合查看“课程要求是否被逐项满足”。

## 4. 关于 PPT

- 当前仓库中的 `ppt制作/项目展示_无动画.pptx` 继续保留。
- 但本轮项目决策已明确：**HTML 是主答辩材料，PPT 仅作为备份可能**。
- 因此，终版归档时不再以 PPT 是否“最精美”作为项目完成度核心标准。

---

## 5. 收尾建议顺序

1. 优先检查 `项目展示.html`
2. 再检查 `README.md` 与 `paper/manuscript_v1.md`
3. 然后检查 `docs/课堂进度对照矩阵.md`
4. 最后再看 `reports/` 中的深度支撑材料
